# Generate Video Metadata — Batch

Generates titles, descriptions, keywords, and categories for video clips. The graph is the same as the image workflow — import files, loop, analyze, parse JSON, build metadata, save, export CSV — but the analysis prompt is written for footage: it describes subject, action, and setting in the present tense, covers motion, mood, and use-case in the keywords, and deliberately avoids camera jargon that buyers do not search for.

Use it when submitting MP4/MOV clips in bulk and the metadata needs to read like a stock video listing rather than a photo caption.
